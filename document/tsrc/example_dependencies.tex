Versat compiles a dataflow-graph specification, written in the Versat specification language, into synthesizable Verilog for the resulting accelerator and matching C/C++ driver code that lets a host program configure and run it. The example that runs through the rest of this section, \texttt{SimpleExample}, is a minimal accelerator that adds two software-configurable constants together and stores the result in a register; it exists to show the full path from a short specification file to an accelerator that software can configure, run, and read results from.

The example needs three artifacts beyond the tools listed above, all bundled in this repository under \texttt{examples/simple\_example}:

\begin{itemize}
  \itemsep-0.5em
  \item \texttt{simple\_example.versat} -- the accelerator's dataflow-graph specification, which Versat compiles into hardware and software.
  \item \texttt{main.cpp} -- a host program that configures the accelerator, runs it, and prints the result.
  \item \texttt{Makefile} -- builds Versat's generated PC emulation of the accelerator, links it with \texttt{main.cpp}, and runs the resulting program.
\end{itemize}
