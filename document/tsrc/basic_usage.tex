Once built, the \texttt{versat} binary takes a specification file, written
in the Versat specification language, and the name of the top-level module
to generate as command line arguments:

\begin{verbatim}
./versat -h
# or
./versat --help
\end{verbatim}

Every Versat run reads a file that defines a top-level name and one or more
accelerators as dataflow graphs, and produces:

\begin{itemize}
  \itemsep-0.5em
  \item synthesizable Verilog source files implementing the CGRA fabric for
    the specified accelerator; and
  \item matching C/C++ software source and header files that let a host
    program configure the accelerator and run it.
\end{itemize}
